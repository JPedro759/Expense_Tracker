# Expense_Tracker

Expense Tracker é uma aplicação web responsiva desenvolvida com <strong>Angular</strong> no front-end e <strong>ASP.NET Core</strong> no back-end, utilizando o <strong>SQL Server</strong> como banco de dados. O sistema permite aos usuários gerenciar suas finanças pessoais de forma eficiente, oferecendo funcionalidades para cadastrar, editar, e remover despesas e rendas.

1. <strong>Tela de Maintenance:</strong> permite que o usuário gerencie suas transações financeiras, incluindo despesas e rendas. Nela, o usuário pode adicionar novas transações, especificando o tipo (despesa ou renda), o valor, a data e uma descrição para organizar melhor suas finanças. Também é possível editar informações de transações já cadastradas, permitindo ajustes em dados como valor, data e descrição. Caso o usuário queira remover alguma transação, a opção de exclusão está disponível para manter o histórico atualizado. A interface foi desenvolvida com Angular Material para uma experiência de usuário intuitiva, com validações de entradas incorretas e feedback visual em cada ação.
2. <strong>Tela de View Data:</strong> exibe um resumo financeiro detalhado para cada registro mensal, facilitando o acompanhamento das movimentações financeiras. A exibição começa com o mês e ano, que indica o período do resumo. Em seguida, é apresentado o campo Savings (Poupança), que mostra o total de economia acumulada até aquele mês, refletindo o valor disponível após a subtração das despesas das rendas. O campo Expenditures (Despesas) exibe o valor total das despesas registradas no mês, permitindo o controle dos gastos. Já o campo Earnings (Rendas) informa o total de rendas, abrangendo todas as fontes de receita cadastradas pelo usuário. Por fim, o campo Previous Savings (Poupança Anterior) indica o saldo acumulado do mês anterior, servindo como referência para acompanhar a evolução financeira ao longo do tempo.
